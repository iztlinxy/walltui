# Changelog

All notable changes to this project will be documented in this file.

## [1.4.2] - 2026-09-06

### Added
- Download screen now shows a live progress bar and percentage inside the downloads table.
- Downloads screen footer shortcut: `o` opens the download folder.
- Gallery footer shortcuts: `Enter` applies wallpaper, `o` opens folder, `r` renames, `d` deletes.

### Changed
- Downloads screen uses the full width for the downloads list; the right-side preview panel was removed.
- Gallery `Enter` key now applies the selected wallpaper instead of opening the image.

### Fixed
- Gallery footer now has enough height to display keybinding hints.
